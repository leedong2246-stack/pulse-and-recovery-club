# Pulse And Recovery Club

Create a modern, sleek multi-sport activity and recovery tracking web application called "PulseBalance". 

Target users are multi-sport enthusiasts doing Gym (Weightlifting), Running, Climbing, and Soccer/Football.

Design & UI Requirements:

- Modern Dark Mode Theme with neon green (#10B981) and vibrant orange accent colors.

- Mobile-first responsive layout (looks like a clean native mobile app on small screens, and a dashboard on desktop).

- Top navigation bar with user profile, today's date, and quick action button "+ Log Workout".

- Clean bottom navigation (Mobile) or sidebar (Desktop) with tabs: "Dashboard", "Log Activity", "Recovery AI", and "Mate Finder".

Please write clean React code with Tailwind CSS and Lucide Icons. Start by creating the overall app shell and layout with mock data.
